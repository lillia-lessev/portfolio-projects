# Sticky Notes Application

This Django Sticky Notes application allows users to create, view, edit and delete sticky notes. 
Users can view all sticky notes as well as individual ones.

## Table of Contents

- [Features](#features)
- [Installation](#installation)
- [Usage](#usage)
- [Contributing](#contributing)
- [Running Tests](#running-tests)
- [License](#license)

## Features

- View all sticky notes
- View individual sticky notes
- Create new sticky notes
- Update/ Edit sticky notes
- Delete sticky notes

### Tech Stack

- **Python**
- **Django**
- **SQLite3**
